Secrets for the LLM tools. Set once here on the Mac; changes apply live (no restart). Tokens are stored on the orchestrator and never shown back.

Directions (Mapbox)

Enables the directions_lookup tool — distance, travel time, and live traffic. Get a token at account.mapbox.com. Requires directions.provider = "mapbox" in the config file (the default).

Weather

Backs the weather_lookup tool and the ambient icon + temperature beside the clock. Visual Crossing (default) needs an API key from visualcrossing.com and resolves the forecast in one request; Open-Meteo is keyless. Changes apply live — no restart.

Places (Google)

Enables the places_lookup tool — a place's address, hours, rating, phone, and a photo, shown on the display. Get a key at console.cloud.google.com (enable the Places API (New)). There is no keyless fallback: no key ⇒ the tool is not advertised. Changes apply live — no restart.
