The text-embedding backend for GraphRAG memory. Switching is live (no restart) and lossless: each backend keeps its own vector index, and your durable memories (SQLite facts + the chat log) are never touched. The first switch to a backend rebuilds its index from the chat log in the background; switching back reuses it.

Embedding backend

Local (nomic-embed-text-v1.5) runs on-device — offline, no API key, 768-dim. OpenAI (text-embedding-3-small) sends memory text to OpenAI and needs OPENAI_API_KEY. The two use different vector spaces, so each has a separate store.
