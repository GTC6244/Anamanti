Fix words the speech-to-text reliably mishears. Whisper has no pronunciation dictionary, so coined or local names (store brands, place names) come back misspelled. Each rule rewrites known mis-heard forms to one canonical spelling, applied to the transcript before it reaches the assistant. Changes apply live, no restart.

Rewrite table (JSON)

A JSON array of rules. Each rule has a canonical spelling and a list of variants — the mis-heard forms to rewrite to it. Variants match whole words/phrases, case-insensitively. Derive the variants from how the word sounds (e.g. "Zehrs" is said zay-rz). Do not put phonetic spellings in canonical — that is the text that gets inserted verbatim.

Danger zone

⚠
Saving replaces the entire table with what is in the box. Blank canonicals, blank/duplicate variants, and a variant identical to its canonical are dropped automatically; a rule left with no usable variants is discarded.
