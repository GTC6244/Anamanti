Embeddings

The model that turns memory text into vectors for recall. Switching applies immediately and is lossless: each backend keeps its own vector store, and the SQLite facts and chat log are never touched. The first switch to a backend rebuilds its index from the chat log in the background; switching back reuses it.

OpenAI embeddings read OPENAI_API_KEY from the environment at boot. A key entered on Intelligence is used by the LLM only.

Entity extraction

Builds people, place and topic nodes from each turn so recall can follow relationships (“what did Sam say about the cabin?”). It is the one memory step that calls a cloud model even when everything else is local.
