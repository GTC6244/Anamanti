Give the assistant a speaking personality. This is pure output tuning — it only changes how replies sound, never what the assistant knows, remembers, or does. Turn it on or off (and switch personalities) by voice too: just say "talk like a 1940s gangster" or "go back to normal". Changes apply live, no restart.

Status

The master switch and which personality is active. Saying "go back to normal" (or picking Normal (off)) turns it off.

Personalities

The catalog the assistant can speak in. The key is the short name used by voice ("talk like a gangster"); the style instruction is appended to the prompt to shape the voice. Edit freely — have fun with it.

Danger zone

⚠
Removing a personality and clicking Save permanently deletes it. If you delete the one that's currently active, the assistant falls back to its normal voice.
