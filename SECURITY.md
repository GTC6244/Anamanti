# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub instead: go to the
[Security tab](https://github.com/Ixiom-Software/Anamanti/security) of this repository and
click **Report a vulnerability**. Only the maintainers can see the report.

Please include:

- what is affected (Display app, Anamanti Core, companion app, or website) and which version;
- steps to reproduce, or a proof of concept;
- the impact you expect.

We will acknowledge the report as soon as we can and keep you updated while it is fixed.

## Supported versions

Only the latest release receives security fixes.
